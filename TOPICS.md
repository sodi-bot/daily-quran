# Curriculum: Qur'an × Bible, through a Lutheran lens

Work through these in order, one per day; the next card is the first row whose `#` is not yet used
in any `cards/*.json` (`topic` field). After the last row, start again from 1 with a different
angle on each pairing. The "angle" column is a starting point, not a script: verify every claim
before using it, and drop or change an angle you cannot verify.

Columns: Qur'an passage · parallel (Bible ref, or a non-biblical text marked *) · relation · angle
